# CRUD App

A beginner CRUD application built with JavaScript.

The project focuses on practicing core CRUD operations and storing data using localStorage.

## Features

- Create data
- Read/display data
- Update existing items
- Delete items
- Data persistence with localStorage

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

- CRUD logic
- Working with arrays and objects
- Updating the DOM dynamically
- Saving and retrieving data from localStorage
- JavaScript event handling

## Future Improvements

- Better UI styling
- Search and filtering
- Backend database integration
- Authentication system
